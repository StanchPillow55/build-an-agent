## 🎯 Learning Objectives

By the end of this session, you will be able to:

- Set up the IDE with required extensions and workspace settings.
- Create a Git branching workflow (feature/release/hotfix) and open a test PR.
- Implement a unit-test harness and run a passing local test suite.
- Measure baseline problem-solving speed on two LeetCode problems.
- Explain how to submit weekly artifacts (code, notes, and reflections).

### Prerequisites
- Identify basic CLI usage (cd, ls, mkdir) and PATH concepts.
- Describe the difference between compiled vs interpreted tooling.
- Recall what unit tests assert and why deterministic tests matter.

<!-- DO/DON'T for Setup Week - Success With SCE Style -->
<div class="two-column">

<div class="do">
**Set up a consistent development environment**
- Use the same IDE/editor for all practice
- Install essential extensions (linting, formatting)
- Configure Git with your real name and email
- Create a dedicated folder for interview prep
</div>

<div class="dont">
**Don't jump around between tools**
- Avoid switching IDEs mid-preparation
- Don't skip version control setup
- Don't use your work/personal email for practice repos
- Don't overcomplicate your environment
</div>
